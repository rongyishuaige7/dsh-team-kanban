## 1. 一句话总结
重构看板视觉物理与微交互架构，引入空间景深分层微物理（Spatial Elevation）、进行中任务环绕量子极光光束（Aurora Orbital Beam）与算力呼吸渐变（Compute Hearth）、双层声呐脉冲雷达（Sonar Radar Ping）、依赖血缘神经网络导流（Neural Lineage Flux）、以及全达成时刻的北极光掠影庆典（Aurora Sweep），并在原型中集成专属庆典与动效演示操作。

## 2. 核心实施特性

| 模块 | 升级前 | 0.3.0 升级后 |
|---|---|---|
| **任务卡片微物理** | 静态纯色背景，hover 仅微变底色 | 空间分层多级环境光投影；hover 弹性上浮 -2px 并扩散空间软阴影；active 实体微受压回弹 |
| **进行中任务态** | 左侧静态 2px 细条，无呼吸感 | 四周环绕 360° 极光流光束（`conic-gradient` + `@property --tkb-angle`）；内部深层算力微呼吸；左侧晶体微能量滑槽 |
| **活跃智能体指示** | 普通静态/微闪烁小圆点 | 智能体头像与绿点外环绕以 1.8s/2.2s 周期向外扩散淡出的双层声呐雷达波纹（Sonar Radar Ping） |
| **任务完成体验** | 单纯压成灰淡单行字 | Spring Pop 弹性过冲与 Checkmark 签名式笔画展开；卡片表面掠过 45° 晶体抛光扫光线（Phosphor Sweep） |
| **依赖血缘悬停** | 仅边框换浅色，无流向感知 | 电影级暗房景深聚焦（非关联模糊暗化）；上游卡片涌动琥珀金/翡翠绿输入流；下游卡片点亮科技蓝输出等待流 |
| **顶部进度条与庆典** | 普通硬质矩形切片拼接 | 量子液体能量导管质感；进行中切片带有粒子光斑冲刷纹理；全部达成触发金色光晕爆发与北极光掠影（Aurora Sweep） |
